#🌟 Project2 - Nền tảng thực hành lập trình C++ 🌟
📌 Giới thiệu
Chào mừng bạn đến với Project2 – một nền tảng luyện tập lập trình đầy tiềm năng, lấy cảm hứng từ các trang web đình đám như LeetCode hay Codeforces! 🎯

Hiện tại, nền tảng này tập trung hỗ trợ ngôn ngữ C++, giúp sinh viên và lập trình viên có thể rèn luyện kỹ năng qua các bài tập thực hành trực tuyến. Hệ thống cho phép viết code trực tiếp trên trình duyệt, biên dịch và chạy chương trình ngay lập tức! ⚡

🔥 Tính năng nổi bật
✅ Viết code trực tiếp trên trình duyệt mà không cần cài đặt môi trường phức tạp.
✅ Chạy và kiểm thử chương trình ngay lập tức với phản hồi nhanh chóng.
✅ Giao diện thân thiện, dễ sử dụng, phù hợp với cả người mới học lập trình.
✅ Hỗ trợ C++ – bước đầu xây dựng nền tảng vững chắc để mở rộng sang các ngôn ngữ khác.

🛠️ Công nghệ sử dụng
💡 Backend: Được xây dựng bằng Spring Boot theo mô hình MVC, đảm bảo tính ổn định và mở rộng dễ dàng.
🎨 Frontend: Sử dụng Thymeleaf, giúp kết nối giữa backend và giao diện một cách mượt mà.
💾 Cơ sở dữ liệu: Tích hợp với hệ thống quản lý dữ liệu mạnh mẽ để lưu trữ và xử lý các bài tập lập trình.

🚀 Mục tiêu phát triển
🌱 Hỗ trợ thêm nhiều ngôn ngữ lập trình như Java, Python, JavaScript trong tương lai.
🏆 Cung cấp hệ thống xếp hạng, đánh giá và bảng xếp hạng để tăng tính cạnh tranh và động lực học tập.
📢 Mở rộng thành một nền tảng thi lập trình online dành cho sinh viên và lập trình viên.
